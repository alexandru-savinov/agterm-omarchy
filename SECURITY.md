# Reporting a security vulnerability

For suspected vulnerabilities in this Omarchy fork, use GitHub's [private vulnerability report](https://github.com/alexandru-savinov/agterm-omarchy/security/advisories/new).
Sign in to GitHub, open this repository's **Security and quality** tab, and choose **Report a vulnerability**.
Private vulnerability reporting is enabled for this repository.
See [GitHub's reporting instructions](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately) if the entry point is unfamiliar.

Include the affected commit or artifact/version, architecture and relevant dependency versions, reproduction steps or a minimal proof of concept, and the impact you observed.
Use a private test environment and remove credentials or unrelated personal data from evidence.
Keep vulnerability details in the private report while coordinating with maintainers; ordinary public issues and Discussions are for non-security support.

This port is under development; no stable security-support window or response-time commitment is declared.
Reports should identify the exact build rather than assuming every upstream or Linux version is affected.
If the issue belongs to upstream agterm, the shared Linux frontend, or a dependency, mention that in the report so it can be routed with the appropriate maintainers.
For ordinary bugs and compatibility questions, use [SUPPORT.md](SUPPORT.md).
